CHAT DDT — MODERN DYNAMIC MOBILE UI V22

FOKUS VERSI INI
- UI mobile modern dan dinamis.
- Navigasi bawah lebih rapi dan proporsional.
- Daftar percakapan memakai kartu modern dengan status realtime.
- Chat bubble, header, composer, modal, dan tema diperhalus.
- Gerakan pesan saat mengirim tetap dinonaktifkan agar tidak membuat pusing.
- Push notification ditunda dan tidak disertakan pada paket ini.

CARA PASANG
1. Salin daftar Gmail ALLOWED_EMAILS dari auth.js lama bila Anda pernah menambahkannya.
2. Timpa seluruh file website dengan isi folder ini.
3. Upload dan publish kembali.
4. Tutup semua tab CHAT DDT dan buka kembali.
5. Jika memakai Home Screen iPhone, hapus ikon lama lalu pasang ulang bila cache masih menampilkan UI lama.
