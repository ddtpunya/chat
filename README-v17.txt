CHAT DDT Mobile Keyboard & Themes v17

Perubahan utama:
- Composer/kolom ketik menjadi baris terakhir yang selalu terlihat saat keyboard mobile terbuka.
- Saat input pesan difokuskan, viewport dan posisi scroll disinkronkan beberapa kali mengikuti animasi Safari.
- Pesan otomatis kembali ke paling bawah ketika keyboard dibuka.
- 5 tema mobile nyaman mata: Midnight Blue, Ocean Calm, Forest Soft, Graphite Dark, Dusk Purple.
- Tema disimpan di localStorage dan dapat dipilih melalui Pengaturan > Tema tampilan mobile.

Pemasangan:
1. Timpa seluruh file website dengan isi folder ini.
2. Publish ulang.
3. Tutup seluruh tab CHAT DDT di Safari.
4. Buka lagi dan lakukan refresh satu kali.
5. Bila dipasang di Home Screen dan masih membaca cache lama, hapus ikon lama lalu pasang kembali.

Firestore Rules tidak berubah secara fungsional dari v13/v16, tetapi file disertakan agar paket lengkap.
